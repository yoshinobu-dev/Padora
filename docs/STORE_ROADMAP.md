# Padora — ストア公開までのロードマップ

> **現在地（2026-08）:** Phase 1 完了・Phase 2 実質完了。  
> 自分用として **実用リリース可能**。Google Play 公開には **配布整備・法務・Pro/無線（任意）** が残る。

関連: [`PRODUCT.md`](PRODUCT.md)（プロダクト定義） / [`README.md`](../README.md)（使い方）

---

## 1. 公開の定義

| 段階 | 内容 | ゴール |
|------|------|--------|
| **A. クローズド配布** | APK + Host ZIP を知人・Discord 等で配布 | 不具合・UX フィードバック |
| **B. オープンベータ** | Play **内部テスト** / **クローズドテスト** | 端末差・接続手順の検証 |
| **C. ストア公開 v1** | Play **本番**（無料 Padora） | 誰でも APK を sideload 不要で入手 |
| **D. Pro 公開** | アプリ内課金（Padora Pro） | 無線・プロファイル等の収益化 |

**Host（Windows）は Play に載せない。** ストア説明・GitHub Releases・公式サイトから ZIP 配布する。

| ステップ | 名称 | 主な成果物 | 目安 |

## 4. ステップ詳細

### S1 — 配布整備（技術）

**目標:** 第三者が README なしでも「ZIP と APK だけで」試せる。

#### Android

- [x] リリース用 **keystore** 作成・安全保管（`scripts/setup-android-signing.ps1`）
- [x] `build.gradle.kts` に **release signingConfig** 設定
- [x] `versionCode` / `versionName` 運用（`pubspec.yaml` + `app_version.dart`）
- [x] アプリ内 **設定 → バージョン** 表示
- [x] ProGuard/R8 は現状維持で可（最小構成）

#### Windows Host

- [x] `dotnet publish` **self-contained + single-file**（win-x64）
- [x] 出力先 **`dist/host-win64/`** に一本化
- [x] **`Padora-Host-win64.zip`** 1 ファイルで配布
- [x] exe **AssemblyVersion**（csproj + ウィンドウタイトル）
- [ ] （任意）コード署名 — SmartScreen 警告軽減（有料・優先度低）

#### 配布チャネル

- [x] ビルド脚本 `scripts/release-s1.ps1` → APK + ZIP + `SHA256SUMS.txt`
- [x] Release notes テンプレ `docs/release-notes/v1.0.0.md` / 手順 `docs/RELEASE.md`
- [ ] **GitHub Releases** へ実際にアップロード（`gh release create`）

**完了条件:** クリーンな PC / 未インストール端末で、手順書 1 枚以内で接続成功。

### S6 — Padora Pro（任意・ストア公開後）

**目標:** 課金理由が明確な Pro。PRODUCT.md Phase 3/4 と一致。

**Pro 設計（合意メモ）**

| 項目 | 無料 v1 | Pro |
|------|---------|-----|
| パッド | 十字＋4ボタン | 十字＋**最大6ボタン**（大4＋小2） |
| 上部チップ | F4 / F11 固定 | **任意キー**（例: F4 全画面＋Ctrl） |
| 斜め | なし（要望時 chord 検討） | カスタム枠に **chord**（↖↗↙↘） |
| 反転 | v1.1 でボタンのみ左右反転（無料） | プロファイルごとに記憶 |
| 接続 | 有線 / Tailscale | **Wi‑Fi 無線**（主軸） |

- 斜めは D-pad 角ロングタップ **非採用**（blind 優先）
- Z/X は **大ボタン**、Shift / Enter / 斜めは **小ボタン**
- v1 は **無料のみ** 公開 → 評価後に S6

**実装タスク**

- [ ] Google Play **アプリ内課金** 設定（サブスク or 買い切り — 要決定）
- [ ] Phase 3: Wi‑Fi 同一 LAN・QR/mDNS 検出
- [ ] Phase 4: 複数プロファイル・複合キー・chord・カラー
- [ ] Pro UI: 6ボタン（大4＋小2）・上部チップ差し替え
- [ ] Pro: プロファイル一式バックアップ
- [ ] 無料 / Pro 機能ガード UI
- [ ] Host 側: 複合キー・Ctrl 等の buttonId 追加

**完了条件:** 無料だけでも v1 価値が維持され、Pro は「無線＋作品別最小キーセット」が動く。

## 6. Host 配布（ストアと並行）

Play 公開前後で共通:

| 項目 | 方針 |
|------|------|
| 形式 | `Padora-Host-win64.zip`（単一 exe 推奨） |
| 取得元 | GitHub Releases（ストア説明からリンク） |
| 更新 | アプリ `versionName` と Host `AssemblyVersion` を README/Release notes で対応表 |
| セキュリティ | v1: 同一 LAN / Tailscale 前提 + 注意書き。β 以降: PIN/HMAC 検討 |
| Microsoft Store | **載せない**（WinForms + SendInput、審査・更新コスト対効果低） |

## 7. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| UDP 無認証 | 同一網からの不正入力 | 注意書き + β で PIN 導入 |
| Host 未インストール | 1 星「動かない」 | ストア説明・初回チュートリアルで強調 |
| SmartScreen 警告 | Host 起動拒否 | self-contained + 将来コード署名 |
| 非公式と誤解 | 削除要請 | 規約・説明で明確化。エンジンロゴ不使用 |
| debug 署名 APK 流出 | 更新不可 | S1 前に必ず keystore 移行 |
| Pro スコープ膨張 | 公開遅延 | v1 は無料のみ固定 |
