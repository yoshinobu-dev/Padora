# Play Store スクリーンショット

| ファイル | 内容 |
|----------|------|
| `01-main-controller.png` | メイン画面（ダーク） |
| `02-settings.png` | 設定（ダーク） |
| `03-main-controller-light.png` | メイン画面（ライト） |
| `04-settings-light.png` | 設定（ライト） |

Play Console → ストアの掲載情報 → スマートフォン用スクリーンショット にアップロード。

**Play 提出の目安:** ダーク 2 枚 + ライト 2 枚（計 4 枚）でテーマ両対応をアピール可。最低 2 枚なら `01` + `02` または `03` + `04` のどちらか一方でも可。
