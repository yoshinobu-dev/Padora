# Google Play — データ セーフティ回答メモ

Padora v1.0.0 時点。Console の質問文は更新されるため、**趣旨** を確認して回答してください。

## 収集・共有の概要

| 質問 | 回答の目安 |
|------|------------|
| アプリはユーザーデータを収集しますか？ | **いいえ**（当方サーバーへの送信なし） |
| データは暗号化して送信されますか？ | UDP 操作パケットは LAN 内平文。当方クラウドへの送信なし |

## 端末内データ（外部送信なし）

| データ種別 | 収集 | 送信 | 必須 | 削除 |
|------------|------|------|------|------|
| PC の IP アドレス | 端末内保存のみ | なし（Host へ UDP はユーザー操作） | いいえ | 設定から可能 |
| アプリ設定（キー・テーマ等） | 端末内のみ | なし | いいえ | アプリ削除 |

## 収集しないもの

- 氏名、メール、電話番号
- 位置情報
- 連絡先、写真、ファイル
- 広告 ID（広告 SDK なし）
- 分析 SDK（Firebase Analytics 等なし — v1）

## 第三者 SDK

Play の「SDK プロバイダー」欄で、使用ライブラリを Declare する場合:

- Flutter engine
- shared_preferences（ローカルストレージ）
- wakelock_plus
- vibration

各 SDK のデータ収集は **アプリ開発者（あなた）が Host/サーバー経由で行わない** 前提で整理。

## 子ども

- COPPA / ファミリーポリシー: 13 歳未満から意図的収集なし
- ターゲットに子どもを含めない場合は Console で適切に選択

## セキュリティ practice

- 転送中の暗号化: **LAN 内 UDP（v1）** — 「業界標準の暗号化で送信」とは言えない場合は正直に
- ユーザーがデータ削除をリクエスト: アプリ内「保存 IP を消す」／アプリ削除

## 更新時

- 分析 SDK 追加 → 本ドキュメントと PRIVACY_ja.md を更新
- クラウド同期追加 → 収集項目を再申告
