# Padora 利用規約

最終更新: 2026年8月

本利用規約（以下「本規約」）は、Padora（Android アプリ、以下「本アプリ」）および Padora Host（Windows 受信ソフト、以下「Host」）の利用条件を定めます。本アプリまたは Host を利用した時点で、本規約に同意したものとみなします。

## 1. サービスの内容

Padora は、スマートフォンの操作を PC へキーボード入力として送る **入力支援ツール** です。ゲームの実行・配布・エミュレーションは行いません。

## 2. 非公式であること

- 本アプリおよび Host は、WOLF RPG エディター、RPG ツクール等の **公式・公認アプリではありません**。
- 各ゲームエンジン・作品の開発元・権利者との提携、許諾、後援はありません。
- エンジン名そのものをアプリ名に用いず、互換性の説明にとどめます。
- 公式ロゴ、公式素材、公認を示す表現は使用しません。

## 3. 利用環境

- 本アプリの利用には、**別途 Host（Windows）のインストールと起動** が必要です。
- スマートフォンと PC は、USB テザリング、同一 LAN、VPN 等で通信可能である必要があります。
- ユーザーは、ファイアウォール設定、ネットワーク設定、OS の更新等を自己の責任で行ってください。

## 4. 禁止事項

以下を禁止します。

- 本アプリ・Host を用いた不正アクセス、第三者 PC への無断操作
- マルウェア配布、スパム、法令違反行為への利用
- 本アプリ・Host の逆コンパイル、改変、再配布（法令で認められる範囲を除く）
- 本アプリ・Host が公式・公認であるかのような表示、宣伝

## 5. キー入力（SendInput）について

Host は、受信した操作指示に基づき PC 上でキーボード入力を注入します。前面のアクティブウィンドウに入力が送られます。意図しないアプリへの入力、データ損失、ゲーム内進行への影響について、開発者は責任を負いません。

## 6. 通信・セキュリティ

- 本アプリと Host は UDP によりローカルネットワーク上で通信します（初期版は認証なし）。
- **同一ネットワーク上の他端末から Host にパケットが届く可能性** があります。信頼できないネットワークでは Host を停止してください。
- 接続に成功した PC の IP アドレスは、**端末内のみ** に保存される場合があります（外部サーバーへ送信しません）。
