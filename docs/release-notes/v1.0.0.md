# Padora 1.0.0

## 含まれるもの

- **Padora.apk** — Android コントローラー
- **Padora-Host-win64.zip** — Windows 受信ソフト（.NET 同梱・単一 exe）

## 必要環境

- Android スマホ
- Windows 10/11 PC
- 同一ネットワーク（Tailscale / LAN / USB テザリング等）

## クイックスタート

1. PC で `Padora.Host.exe` を起動（ファイアウォール許可）
2. 表示された **PC の IP** をアプリに入力して接続
3. ゲームウィンドウを前面にして操作

## 主な機能

- 十字キー（短タップ＝1マス、長押し＝連続移動）
- 決定 / 取消 / Shift / カスタム / F4 / F11
- 短タップ触覚（十字・決定・取消・Shift・カスタム）、前回 IP 記憶
