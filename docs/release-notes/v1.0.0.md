# Padora 1.0.0（プレリリース）

> Google Play 本番公開前の配布用ビルドです。

## 含まれるもの

- **Padora.apk** — Android コントローラー
- **Padora-Host-win64.zip** — Windows 受信ソフト（.NET 同梱・単一 exe）

## 必要環境

- Android スマホ
- Windows 10/11 PC
- **USB ケーブル**（テザリング用。v1 の推奨接続）

> v1 には Wi‑Fi 自動検出などの **無線接続機能はありません**。

## クイックスタート（USB テザリング）

1. USB テザリングを有効にする
2. PC で `Padora.Host.exe` を起動（ファイアウォール許可）
3. Host に表示された **PC 側の IP** をアプリに入力して接続
4. ゲームウィンドウを前面にして操作

## 主な機能

- 十字キー（短タップ＝1マス、長押し＝連続移動）
- 決定 / 取消 / Shift / カスタム / F4 / F11
- 短タップ触覚（十字・決定・取消・Shift・カスタム）、前回 IP 記憶
- 設定の書き出し／読み込み（JSON、接続 IP は含まない）
