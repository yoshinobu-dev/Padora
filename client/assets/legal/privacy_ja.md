# Padora プライバシーポリシー

最終更新: 2026年8月

Padora（Android アプリ、以下「本アプリ」）および Padora Host（Windows、以下「Host」）における情報の取り扱いについて説明します。

## 1. 基本方針

本アプリは、**ユーザーの個人情報を収集・販売・共有するサービスではありません**。操作データはユーザーの PC（Host）へ直接送られ、当方のサーバーには送信しません。

## 2. 当方が運用するサーバー

**現行バージョンでは、当方が運用するクラウドサーバーはありません。** アカウント登録も不要です。

## 3. 端末内に保存される情報

以下は **スマートフォン内（SharedPreferences 等）のみ** に保存され、当方へ自動送信されません。

| データ | 目的 | 削除方法 |
|--------|------|----------|
| 接続成功した PC の IP アドレス | 次回起動時の入力省略 | 設定「保存した IP を消す」／アプリ削除 |
| キー割り当て・テーマ・触覚 ON/OFF 等 | アプリ設定の保持 | アプリ削除 |
| 起動時自動接続の ON/OFF | 接続設定 | 設定画面 |

## 4. ネットワーク通信

- 本アプリは、ユーザーが指定した **PC（Host）の IP アドレス** へ、UDP パケット（ボタン操作）を送ります。
- 通信内容はゲーム操作（方向・決定等）に限られ、位置情報・連絡先・写真等は含みません。
- VPN、家庭 LAN、USB テザリング等、**ユーザーが選択した経路** で通信します。

## 5. Host（Windows）側

- Host は PC 上で UDP を受信し、キー入力を注入します。
- Host が当方のサーバーへ利用状況を送る機能は **ありません**（現行版）。
- Host のログ表示は **ローカル画面内** のみです。

## 6. 第三者 SDK・ライブラリ

本アプリは以下を含みます。各提供者のポリシーも適用される場合があります。

| 名称 | 用途 |
|------|------|
| Flutter | アプリフレームワーク |
| shared_preferences | 端末内設定保存 |
| wakelock_plus | 画面スリープ防止 |
| vibration | 触覚フィードバック（Android） |

Host は .NET / Windows Forms を使用します。

## 7. 子ども向け

本アプリは、13 歳未満の子どもから意図的に個人情報を収集しません。

## 8. 変更

本ポリシーは必要に応じて更新します。重要な変更がある場合は、アプリ内または https://github.com/yoshinobu-dev/Padora/releases で告知します。

## 9. お問い合わせ

プライバシーに関する問い合わせ: https://github.com/yoshinobu-dev/Padora/issues

**Google Play「データ セーフティ」回答の目安**

- 個人データを **収集しない** / または **収集しても外部送信しない**
